# 代码审阅优化实施记录

本轮优化保持现有 Rust 服务、CPU/GPU 渲染后端、原生管理界面和离线 OpenLayers 架构。
不引入样式库，不改变托管数据格式，不自动扩大并发、绕过内存预算或重试失败请求。

## 十项修改

| 项目 | 实施方式 | 正确性约束 |
| --- | --- | --- |
| 栅格重采样 | 复用逐波段累加数组；nearest 直接复制原生样本，跳过浮点插值工作区 | 保留 NoData、有效性掩码、alpha、整数精度及校准语义 |
| 派生矢量读取 | 每个游标复用当前分片的缓冲文件句柄；连续记录免 seek；候选索引按实际数量记账 | 不同时打开所有分片；仍验证分片和索引校验和，保持源顺序 |
| 栅格窗口读取 | 从窗口直接计算规则块网格的行列区间，不遍历整个 level 的块清单 | 保持边缘窗口、概览权重与块缓存行为 |
| 目录并发 | 只读路径取得不可变 Arc 快照，写入由独立 writer 锁串行；缩短状态锁持有时间 | 保留 ETag、持久化原子切换、崩溃恢复；pin 注册与快照切换互斥；删除期间拒绝新 pin |
| 注记布局 | 请求内复用字体系统、shaping 结果和字形轮廓；碰撞测试使用空间网格索引 | 保留显式字体隔离、优先级、确定性顺序和跨瓦片一致性；大包围盒走回退路径 |
| 数据选择与概览 | 对可确定范围的矢量查询下推带符号余量的 bbox；投影栅格采样局部像素足迹选择概览 | 动画几何目标额外加入候选；不能安全推断时回退，见下节 |
| 预览清晰度 | WMTS 使用原生离散缩放级别；单图按屏幕 DPR 和服务端尺寸预算请求，缩放像素样式 | WMTS 仍为原生 256 像素瓦片；不伪造高分屏瓦片，不改变地图单位样式 |
| 管理列表竞态 | 资源列表、任务列表使用请求序号，只允许最新结果更新页面 | 已发出的旧请求仍在响应体完成后释放调度槽位，不提前释放并发许可 |
| Features 集合分页 | 支持严格的 offset/limit 查询，返回 self/next 链接及目录 generation | 只列公开矢量集合；非法、未知、重复参数拒绝；目录变化时调用方可检测 generation |
| WebSocket 连接预算 | 独立会话限额、连接期内存记账、定时 Ping、入站空闲超时 | 保留 init/send 超时；Pong 刷新空闲时间；输出缓冲上限依据图像预算，不限制为控制帧大小 |

## 安全回退

### 矢量空间选择

目前只对相同 CRS，以及有效世界范围内单调的 `OGC:CRS84` 与 `EPSG:3857` 转换，
下推常量符号范围。动态数值样式、样式动画、无法确定的符号范围和其他 CRS 转换使用完整查询。
几何动画目标即使原始位置在视窗外也会被保留，并按原始源顺序合并；其他属性过滤仍然生效。

当场景任意样式含注记时，所有项目保留完整查询，而不是仅取消注记图层的筛选。
这是为了保持全局碰撞链、候选优先级、视窗外点标记避让及相邻瓦片注记选择不变。
因此本轮不承诺所有地图或含注记地图都消除全量扫描。

### 投影栅格概览

同 CRS 继续使用原有仿射足迹选择；跨 CRS 对视窗与源影像各进行有界网格采样，
以局部反投影 Jacobian 的最小缩放量和半尺度安全余量选择概览。
没有有效样本、采样尺度变化超过四倍或不能构建辅助投影时回退基础层。
不适用既有概览采样语义的重采样方法也保留基础层。

这是保守采样估计，不是任意不连续投影的数学误差界。实际渲染仍执行自己的投影和
有效域检查；规划阶段跳过不可用样本，不会吞掉实际渲染的其他错误。

### 注记缓存

缓存只在单个布局请求内存在，不跨地图、字体栈或请求共享可变字体状态。
shaping 结果最多 128 条，字形轮廓最多 256 条，各有约 4 MiB 上限；
字体工作区累计到阈值后重建字体栈，缓存和碰撞索引均参与操作预算。
字体 identity、字体字节对象、语言和显式字体序列必须一致才能复用。

## 新增接口与配置

### 高分屏地图图像

基础地图图像、OGC Maps 单图及 WMS GetMap 接受可选 `geello_pixel_ratio`，
默认 `1`，必须为有限正数且不超过 `4`。`width/height` 或 `WIDTH/HEIGHT` 始终是
实际输出像素数，比例控制符号的像素尺寸，不会自动将图像尺寸再乘一次。

例如逻辑 800×600、DPR=2 的画布应请求 1600×1200 和 `geello_pixel_ratio=2`。
像素线宽、点大小、注记大小和像素虚线同步缩放；地图单位保持不变。
比例纳入单图渲染缓存键；旧缓存使用不同版本键，不会混用。

管理台的单图 DPR 最多为 2，同时受 `max_dimension` 限制；必要时允许小于 1 的有效比例。
对世界范围裁剪时同步调整图像尺寸及 OL 的 resolution/pixelRatio，避免拉伸。
WMTS 使用服务声明的原生级别，不支持该比例参数；高分屏显示仍受原生瓦片分辨率限制。

### Features 集合分页

`GET /ogc/features/collections?offset=0&limit=50` 返回有界分页。
`limit` 默认 `max_list_items`，范围为 `1..=max_list_items`，`offset` 默认 0。
响应包含 `x-geello-generation` 字段；这不是跨请求固定快照游标，翻页期间发布发生变化时
调用方应检测 generation 并按需从第一页重载。Features 要素查询的固定快照机制不变。

### WebSocket

在现有 `[profile]` 中可选配置：

```toml
max_websocket_sessions = 64
websocket_idle_timeout_ms = 120000
```

旧配置省略时使用以上默认值。会话数必须为正；空闲超时至少为 100 ms，且时间可表示。
`GET /api` 的 `x-geello-enabled` 暴露生效限额。

WebSocket 会话占用独立许可，不再只依赖升级请求的 HTTP 许可；满额升级返回 503。
每条连接保留基础缓冲内存，并在发送较大图像前按高水位追加内存预留，直到连接结束才释放，
避免网络库已扩容的缓冲区失去记账。内存预算仍可能比会话数上限更早拒绝请求或暂停帧发送。
入站控制消息、帧上限均为 64 KiB；出站图像上限遵循 `max_image_bytes`，可以超过 128 KiB。
服务每隔空闲超时的三分之一发 Ping；收到消息或 Pong 才重置空闲时间，持续出图不能
代替客户端存活证明。超时发送 Close，断开后释放会话许可、内存和资源 pin。

## 回归验证

新增回归覆盖空间筛选动画豁免及源顺序、投影概览选择、字体缓存隔离与释放、
碰撞索引等价性、目录读写锁分离、删除期间 pin 禁入、高分屏符号尺寸与缓存隔离、
集合多页查询、列表乱序响应、WebSocket 会话耗尽/归还、心跳空闲关闭和大二进制帧。
保留既有投影域、整数/NoData/alpha、动画、持久化恢复及跨瓦片注记契约测试。

```sh
cargo fmt --all -- --check
cargo test --locked --features server-full
cargo test --locked --no-default-features
cargo test --locked --no-default-features --features server,render-cpu,read-geojson,read-shapefile,read-geotiff
node --test tests/admin_requests.test.mjs
python tools/generate_http_docs.py --check
```

浏览器验收使用独立测试服务，不对现有运行服务发布或删除资源。

本记录不宣称固定吞吐提升百分比；真实性能应在相同数据、视图、后端和预算下另做基准比较。
