Geello HTTP API

Experimental application contract · OpenAPI 3.0.3

Download the JSON contractMap imagesTilesResource uploads

Requests below are relative to the configured public base URL, including any reverse proxy prefix. The JSON document reports that URL and this binary's enabled readers, backend and selected profile limits. Forwarded headers and Host do not override it.

Writes require exactly one conditional header: If-None-Match: * for absent resources or a current strong If-Match ETag for replacement/deletion/unpublish. Poll accepted operations until ready or failed. Deployments protect administration and TLS through their reverse proxy.

Typed query names are case-sensitive; legacy KVP names are case-insensitive. Unknown and duplicate fields fail. GET routes also support HEAD. Errors use RFC 9457 application/problem+json or legacy protocol exception XML. Features supports fixed snapshots; WFS supports the bounded KVP/XML GeoJSON query subset; WebSocket supports latest-state updates, refresh, playback and PNG/JPEG pairs. No official OGC certification is claimed. This guide is static and works without JavaScript or external assets.

GET /ws/maps/{id}

Upgrade to the tested WebSocket map subset

One-map WebSocket protocol 1. No URL query. Hello precedes init; init/update/retry use ASCII request IDs up to 128 bytes and atomic complete view/variant/playback/output groups. Variant is {id:'default'}. Output supports png or jpeg (explicit jpeg_quality 1-100), default 30 fps and profile ceiling. Accepted controls receive ack in receive order; superseded unstarted frames are discarded, so each ack does not promise a frame. One pending render and one serial writer bound backpressure; a started frame metadata/image pair completes before any later control/event. Metadata carries frame_id, control revision, resource render_revision, time, content_type and bytes. Playing uses a monotonic speed-scaled clock; paused updates redraw. Refresh emits resource-changed and redraws paused state; unpublish finishes any started pair then emits resource-unpublished and closes. Render failure suspends automatic frames until valid update/retry succeeds. Animation work bypasses HTTP caches. Init and each send have operation deadlines; timeout closes. Reconnect is client-owned with complete init against current resources.
